# Reeltor

MVP-сайт подбора недвижимости в **Грозном (Чеченская Республика)** на Django: каталог, фильтры по району, карточки объектов, заявка на персональный подбор, роли (клиент / риелтор / админ) и Django Admin.

Интерфейс на русском. Другие города в каталоге и демо не предлагаются.

## Возможности MVP

- **Каталог только по Грозному** — продажа/аренда, тип, район, комнаты, цена, площадь, текстовый поиск
- **Карточка объекта** — характеристики, риелтор, похожие объекты
- **Подбор** (`/podbor/`) — заявка клиента; заявки видны в админке
- **Роли пользователей** — клиент, риелтор, админ (`accounts.User`)
- **Админка** — объекты, пользователи, заявки на подбор
- **Стиль** — зелёная палитра, светлый фон, тёплые акценты, лёгкие орнаментальные мотивы

## Быстрый старт

Требуется Python 3.11+.

```bash
# 1. Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Миграции
python manage.py migrate

# 4. Суперпользователь (админ сайта)
python manage.py createsuperuser

# 5. (опционально) демо-объекты по Грозному и риелтор
python manage.py seed_demo

# 6. Запуск
python manage.py runserver
```

Откройте:

- сайт: http://127.0.0.1:8000/
- каталог: http://127.0.0.1:8000/catalog/
- подбор: http://127.0.0.1:8000/podbor/
- админка: http://127.0.0.1:8000/admin/

## Структура

```
accounts/      # пользователи и роли
properties/   # объекты, заявки на подбор, публичные страницы
templates/    # шаблоны на русском
static/       # CSS
config/       # настройки Django
```

## Роли

| Роль     | Назначение                                      |
|----------|-------------------------------------------------|
| client   | клиент (по умолчанию)                           |
| realtor  | риелтор — можно назначить на объект / заявку    |
| admin    | роль сайта (плюс флаги Django staff/superuser)  |

Наполнение каталога и обработка заявок — через Django Admin.
